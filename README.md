# Sauvegardes les 2M

Outil **privé** de sauvegarde, utilisé uniquement par son propriétaire.

Chaque nuit, une tâche automatique copie la base de données d'une application de gestion
locative privée, la chiffre, puis la dépose dans le Google Drive du propriétaire.

- L'outil n'est pas proposé au public et n'a pas d'autres utilisateurs.
- Il n'a accès qu'aux fichiers qu'il a créés lui-même dans ce Drive (autorisation
  `drive.file`). Il ne lit pas les autres documents.

Règles de confidentialité : [confidentialite.md](confidentialite.md)
